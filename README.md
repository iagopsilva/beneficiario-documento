# Nome do Projeto

## Descrição
Este projeto é uma aplicação desenvolvida com Java 17, Spring Boot, Maven, H2, com foco em **[objetivo do projeto]**. Abaixo estão as instruções sobre como configurar o ambiente de desenvolvimento, executar a aplicação e gerar o build.

## Tecnologias utilizadas
- **Java 17**: Versão do Java usada no projeto.
- **Spring Boot**: Framework para desenvolvimento de aplicações Java.
- **H2 Database**: Banco de dados em memória para desenvolvimento e testes.
- **Maven**: Ferramenta de automação de build.
- **Lombok**: Biblioteca para reduzir o código boilerplate (getter/setter, construtores, etc.).

## Como executar o projeto

### 1. **Pré-requisitos**
Antes de começar, você precisa ter instalado em sua máquina:
- **Java 17** (ou versão compatível)
- **Lombok** (instalado na sua IDE)
- **IDE** (recomendamos IntelliJ IDEA)
  
### 2. **Clone o projeto para sua máquina**
git clone https://github.com/iagopsilva/gestao-funcionarios.git
